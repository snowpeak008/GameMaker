# W7 执行计划（波 0-6 · 任务卡级）

> 2026-09-03 主开发起草。当前版本 **v0.3（两轮评审后定稿，可开工）**。修订记录 §9。
> 依据：`W7_设计方法论重构_定稿.md`（含全部裁决）、附录《系统库缺口扫描》《极端组合形态测试》。
> 协作模式：主开发只派发/集成/验收；子 agent 开发自验收；每波统一门禁（fmt / clippy 零警告 / test 全绿只增 / 双包 validate / cli_smoke 退出码 0 / desktop 构建）；任务卡强制：调研 ≤10 分钟、先跑测试再动手、**断点状态申报节**。

## 0. 范围与不变量

- **做**：定稿 §5 类型系统全量 + §7 迁移 + P0 缺口五模块 + #40 职业 + AI 访谈三段式（含真 AI 验证）+ 桌面端适配 + 样板矩阵（尖塔全量 / lane_defense 重表达 / 自走棋薄样板 / 音游微样板）。
- **不做（显式声明及理由）**：
  - G4b/G5（用户裁暂缓）；
  - 13 模块的 P1/P2 批次与 37 卡量产（样板验证后）；
  - **逆向模板证据重建**（审计 A 整改 ③）：定稿 §7.2 已裁"标 smoke_test 隔离、宁缺勿造"；类型系统大改后按旧模型重建答卷属浪费，**推迟到模块量产波按新模型重建**——此为有理由的推迟而非遗漏（二轮评审判定采纳）。
- **不变量**（每卡携带）：I1 确定性守恒；I2 serde 旧档守恒；I3 校验前置；R1-R7；"旧 407 测试零弱化"口径（helper 适配允许、断言语义零弱化、零删除零 ignore）；无痛接入纪律（**每个**新模块入库验收单均含"仅新增 module.json、零代码改动"项——波 3/波 4 全部模块一体适用）。
- **C4 未交付臂纪律**：穷尽匹配无 `_` 臂；未交付渲染臂返回结构化 `Err("效果变体 X 的需求渲染未交付")` + 负测试锁定；禁 todo!()/unimplemented!()。
- **发版与回滚**：每波一集成 worktree 分支；每卡验收后一提交；波末合入推 GameMaker（补丁位 +1）；波中断丢弃未验收提交。
