## 3. 专打两个已知风险

### 3.1 风险①："重度 = 激活点集"是否把"重"降维成了内容开关

**判定：成立一半，且比两位提案人自首的更严重。** 证据链：

1. 用户原意（简报 §2.3）的"重"含子机制数量、数值深度、交互耦合、心智负担四种内涵（§5 Q2 原文列举）。
2. B 的 `MeasuredWeight` 四字段（B §2.1）：active_points / active_schemas / coupling_width / effect_count——**全部是创作工件计数，无一测"数值深度"（公式复杂度、曲线数）与"心智负担"**。B 自首了这点（§9 风险 1），自首属实不是烟雾弹。
3. **没自首的部分**：A 的五维里 P（决策形态，最接近心智负担）是唯一含判断的维度且 A 自己说"直觉上 P 对玩家感知的重贡献可能更高"（§2.4.3）——而 **B 的测得向量里根本没有 P 的代理量**。也就是说融合后，最重要的维度只存在于人工声明轨，机器轨对它全盲。两个系统激活点数相同、一个纯被动一个构筑级组合，机器测得重度相同——B §9 预言的失真场景在融合模型里必然发生。
4. 第二处没自首的：**A 的 C 维（耦合宽度）依赖系统实例图边数，是组合相对量而非系统固有量**。同一个装备 E2 在幸存者组合里 C=2、在 MMO 组合里 C=6，W 随组合漂移——A §2.2 谱系标定却把 C 预先写死在档位里（E2 档 C=2），**标定表与量表定义自相矛盾**。A 宣称的"装备 E2 与宠物 P3 跨系统等价交换"（§2.3）在 C 维口径下不成立。

**修正方案（进融合指令）**：
- 重度 = **声明档（模块局部 ladder，B §2.1）× 五维标定（A §2.1，作为档位定义的内容标准）× 测得向量（扩维后）** 三件套。
- 测得向量扩到与 A 五维一一对应：M←激活机制数（非决策点数）、D←激活 schema 数且 Graph/Matrix/Curve 加权、C←接口边全口径（consumes+modifies+provides-被消费，按 A §2.1 定义）、O←基数期望行数合计、**P 无机器代理，保留为声明+评审问句（A §2.1 的四问），并在模块档位定义里写死每档的 P 下限**（E2 档定义即要求 P=3，声明 E2 就是承诺构筑级决策——把 P 从测量问题转为定义问题）。
- C 维在**谱系标定中改为"接口边下限"**（E2 档：C≥2），实例图上实测，声明与实测漂移 ≥1 档 → gate2 警告（不 block）。
- 结论：重度不会降维为内容开关的条件是"档位定义携带 P 与数值深度承诺"，纯激活点集轨（B 现方案）单独使用则风险成立。

### 3.2 风险②：R-C1 形态枚举撞墙，例外条款是否等于规则失效

**判定：等于失效。** 证据：A 在一份自证文档内为 F 枚举打了三个补丁（§4.3 "F3+ 修饰器伴生"、§4.6 现场改 F1 定义、§4.7 发明 F4），补丁速度 = 每 3 款游戏一个新形态。照此外推，形态枚举会退化为"每个品类一个例外"，即 A 自己预言的"滑向自由裁量"（§9 攻击点①）。**枚举形态是错误的抽象层级：它枚举的是结果形状，而用户愿景（简报 §2.4）说的是生成原则——"重系统必须与核心强关联、重度相互约束"。**

**组合规则能救，救法是把枚举换成两条连续规则（不动 R-C2/R-C3）**：

- **R-C1′ 重核连通性规则**（替代形态枚举）：设 H = {W≥9 且 κ∈{core,strong} 的实例}。校验：(a) H 的诱导子图必须**连通**；(b) H 中每个节点与 H 内其他节点的接口边合计 ≥2（F3 "强耦合证明"的一般化）；(c) |H| 上限由 L0 档位给出（超休闲 0 / 休闲 1 / 中核 2 / 重核 3 / MMO 4——这是数值参数不是形态枚举，调它不需要改规则）。
- **验证**：杀戮尖塔 H={构筑,战斗,遗物}，遗物 modifies 战斗+构筑、构筑↔战斗双边 → 连通、每节点 ≥2 边、|H|=3 ≤ 中核上限？中核上限 2 → 需 L0 声明重核档（|H|=3 ≤3 ✓）——**通过且语义正确**（杀戮尖塔的设计负担确实是重核级）。MOBA H=4 个，两两强耦合 → MMO/竞技档 |H|≤4 ✓。反例 2（装备+卡组钉在一起）：装备与卡组仅 1 边 → 装备节点 H 内边数 1 <2 → block ✓。F2 并联中核（星露谷）：H=∅ 或按 W≥9 含时钟/栽培 → 两者有日程/生长双边 → 连通 ✓。**四个此前的撞墙/反例全部在无例外条款下正确判定。**
- F0-F3 命名保留为**报告层的形态描述标签**（校验器输出"当前组合呈 F3 双核形态"），不再是校验依据。
