```

【接口契约】adm4_app::AppServices 新方法（*_with 变体收 &dyn AiProvider 供脚本，无后缀版内部 build_provider()）：
- template_new_draft(pack_id, template_id, game_name, aliases: &[String], depth: DesignLevel) -> Template
- template_search_corpus(pack_id, template_id, corpus_root: &Path, decision_question: &str, keywords: &[String])
  -> Vec<EvidenceCandidate>（候选池按 source_url 去重累积，持久化于 <design_space_root>/<pack>/references/.candidates/<id>.json）

写一个冒烟脚本 V4\scripts\cli_smoke.ps1：无人值守走完 逆向五步→预填→访谈补齐→冻结→C0-C6。

cargo test --workspace（全绿）; powershell -File scripts\cli_smoke.ps1（退出码 0）
【禁止】改其他 crate 逻辑/docs/plan/docs/design；git 操作；新增第三方依赖。
【报告】改动清单；任务卡逐条自评；自验收输出摘要；遗留与声明。
```
