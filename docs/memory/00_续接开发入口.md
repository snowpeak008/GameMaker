### T6 CLI 子命令补齐

```
你是 AutoDesignMaker 第四版（V4）的开发子 agent，领取任务 T6「CLI 子命令补齐」。
工作区根 E:\workwork\CrewAi\AutoDesignMaker，项目在 V4\，Windows + PowerShell。

V4\crates\adm4-app\src\services.rs（门面 API 事实）；V4\apps\adm4-cli\src\main.rs（现有命令风格）。
【接口契约】adm4_app::AppServices 新方法（*_with 变体收 &dyn AiProvider 供脚本，无后缀版内部 build_provider()）：
- template_new_draft(pack_id, template_id, game_name, aliases: &[String], depth: DesignLevel) -> Template
- template_search_corpus(pack_id, template_id, corpus_root: &Path, decision_question: &str, keywords: &[String])
  -> Vec<EvidenceCandidate>（候选池按 source_url 去重累积，持久化于 <design_space_root>/<pack>/references/.candidates/<id>.json）
- template_map[_with] -> usize；template_cross_check[_with] -> CrossCheckReport
- template_review(pack_id, template_id, reviewer, note) -> Template；template_certify(pack_id, template_id) -> Template
- template_compare(archive_id, template_id) -> TemplateComparison（只读对照）
- interview_next[_with](archive_id) -> InterviewTurnDto（serde tag "turn"：structural_point/table_proposal/complete；
  其 proposal 必须原样传回 confirm）
- interview_confirm(archive_id, &InterviewProposal, overrides: Option<ParameterValues>) -> Vec<String>（待填清单，非空不阻断）
- interview_reject(archive_id, decision_id, note)；interview_progress(archive_id) -> InterviewProgress
预填走 project_new(..., Some(template_id))，未认证模板 Blocked。
注意：confirm/reject 必须绑定用户手势（D11）；lane_defense 同层拓扑序中 ld.counter_matrix 先于名单表被提案，
冒烟脚本可用"拒绝"先填名单（adm4-app e2e 已示范）；预填理由含模板游戏名会被换皮门拦截属预期，需引导重写。
【任务】只允许修改 V4\apps\adm4-cli\**。新增子命令：
- template：new-draft / import-corpus（或 search-corpus）/ map / cross-check / review / certify
- interview：next / confirm / reject / progress
- prefill：用 Certified 模板预填项目（未认证被拒的错误信息要可读）
全部命令有中文 --help；输出结构化、可脚本断言；AI 相关命令支持通过配置走 ScriptedProvider 以便冒烟。
写一个冒烟脚本 V4\scripts\cli_smoke.ps1：无人值守走完 逆向五步→预填→访谈补齐→冻结→C0-C6。
【自验收】cd V4; cargo fmt --check; cargo clippy -p adm4-cli --all-targets（零警告）;
cargo test --workspace（全绿）; powershell -File scripts\cli_smoke.ps1（退出码 0）
【禁止】改其他 crate 逻辑/docs/plan/docs/design；git 操作；新增第三方依赖。
【报告】改动清单；任务卡逐条自评；自验收输出摘要；遗留与声明。
```
