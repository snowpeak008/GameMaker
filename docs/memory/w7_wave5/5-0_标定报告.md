## 1. 标定口径

- **W** = 声明档映射五维分（M+D+C+P+O 各 0-3，预算单轨制，定稿 §4.3）；**B(G) = Σ W × weight(κ)**，κ 权重 core 1.0 / strong 0.75 / weak 0.5 / meta 0.25。
- 系统分解按边界三测试（T1 独占状态 / T2 可摘除 / T3 名词转换）；κ 按纯结构判据（core_loop 动词绑定 / provides 被核心消费 / modifies core 属性 / 局外）。
- 每款给出**用户直觉档**（任务卡指定）与**设计复杂度档**（预算刻度语义下 B(G) 落带的档）。两者不一致不是错误——预算量的是设计负担，不是市场定位（星露谷判重核档已被 §8 问题 2 裁决确认为正确结论）。
- 射程外内容不计入 W（定稿 §6.5）：手感定稿、netcode、物理多跳涌现、叙事文本本体——CS2 与极乐迪斯科的评分注明了此切分。

## 5. 等权检验与档带检验

### 5.1 五维等权（M+D+C+P+O 等权求和）

**结论：11 款散点上未产生排序倒挂，本轮不改权重公式。** 机器断言：`scatter_of_eleven_samples_matches_grade_bands` 锁定 B(G) 升序与档带对应关系，任何评分/权重改动会先撞红此测试。

两处已知张力如实记录（**上呈项，不动公式**——权重改动影响面大：已入库 11 模块的全部档位标定、四个锚点判例、档带阈值全部要重校）：

1. **O 维（内容供给）在"内容型"与"规则型"系统间语义不完全同质**。音游谱面 O3（数千音符行）与尖塔卡牌 O3（350 卡）都如实计数，但前者是"填表劳动"后者是"每行都是设计决策"。等权下音游谱面系统 W9 与 Candy Crush 棋盘 W9 同带——本轮样本上没有因此产生档位误判（音游 23.0 仍落休闲带，符合直觉），但若未来样本出现"O3 拉高纯内容系统入重核"的误判，调权建议是：**O 维按"行 = 设计决策"与"行 = 内容填充"分横（前者计满、后者减半）**，这需要给 O 维加语义子类，属结构改动，须用户裁决。
2. **C 维是组合相对量**（定稿 §3.2 修订一已声明）：同一系统在不同组合里 C 不同。本标定按各游戏实际组合的实例图数边，与谱系"C≥n 下限"口径一致，无矛盾；但跨游戏比较同名系统时（如幸存者掉落 C2 vs 星露谷商店 C2）数字含义依赖组合语境。这是定稿已知特性不是新发现，记录备查。

### 5.2 档带 4/8/12（轻/中/重/极重分界）

**结论：合理，不建议改。** 证据：

- **W9 重核门槛在 11 款上零误伤零漏放**：入 H 的 24 个实例（各款 H 集之和）逐个核对，全部是该游戏公认的"核心重系统"（尖塔构筑、星露谷时钟栽培、MOBA 四件套、EU4 八件套、极乐迪斯科检定对话技能思维阁…）；未入 H 的边界件（星露谷制造 W8、MOBA 经济 W8、旷野之息化学 W8、CS2 目标 W7）也都经得起反问——它们确实是"重要但可在不改写核心规则的前提下减配"的第二梯队。
- **8/9 分界恰好切在多款样本的"核心/辅助"直觉分界上**：W8 件（制造/经济/化学/任务）与 W9 件（料理/目标占夺/科技/宗教）的差距通常来自 P 或 O 的一档，对应"有没有构筑纵深/内容承诺"——这与"重核 = 设计负担的主要承载者"的语义一致。
- **12/13 极重分界**：样本中触发极重的是尖塔构筑 14、MOBA 技能 15、EU4 外交 14——三者都是"该游戏的招牌深度"，极重带的稀缺性符合预期；E4+ 饱和问题（定稿 §3.6）在本样本集未构成判定障碍。

### 5.3 |H| 参考线（超休闲 0 / 休闲 1 / 中核 2 / 重核 3 / MMO 4）

顺带检验（非本卡主目标）：休闲簇四款 |H| 全部 =1、尖塔 3、旷野之息 3、MOBA/极乐迪斯科 4、EU4 8——参考线与 B(G) 档带的双轨提示在 11 款上方向一致，无互相矛盾的提示对（不存在"数量超线但预算宽裕"或反之的撕裂样本；星露谷 |H|=2 在休闲线上超 1 与预算超 28 同向）。参考线不需调整。
