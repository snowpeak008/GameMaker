## 4. 1c 触发检查结论：**不触发，未改 c4_capabilities.rs**

源码核实：四个诚实 Err 臂 = AreaApply/**Attach**/Detach/RollCheck
（`c4_capabilities.rs::remaining_arms_are_honest_undelivered_err` 锁定，混入即整体 Err）。
任务卡预判路线可完整绕开四臂——全链只用旧 7 变体 + Schedule/ModifyRule/DrawFromPool，
C0-C6 全绿即证明未触臂。**羁绊光环未确需 AreaApply**：羁绊语义是「常驻改写结算规则」，
ModifyRule(scale_coefficient) 是正确表达而非将就（光环=范围施加是 MOBA/RTS 语义，
自走棋羁绊作用于全队结算，无空间范围维度）。

撞臂点走署名 N/A 豁免（engine.set_not_applicable，理由+说明+署名三非空，
冻结门第 1 道逐条在案），**逐条上报主开发**（1c 机动卡交付真渲染后可解除豁免）：

| 决策点 | 撞臂 | 豁免理由（真实设计理由，非借口） |
|---|---|---|
| format_main.bracket_shape | round_robin_points 含 RollCheck | **正名冲突**：「自走棋 8 人循环」的正名选项被未交付臂挡住；单/双败树不符血量淘汰语义。名次结构由 placement_rule（淘汰倒排）承载，赛程结构维度如实缺位 |
| format_main.series_length / tiebreak_rule | 两选项均含 RollCheck | 自走棋无 BO 局分（淘汰制单局），genre 不适用与撞臂重合 |

| board_main.row_effect | 两选项均含 Attach/RollCheck | 站位效果由 pack 羁绊薄点承载 |
| board_main.range_los | 两选项均含 RollCheck | 攻击射程属自动战斗涌现层（射程外声明） |
| squad_main.synergy_bonus | 两选项均含 Attach | **G8 阵型协同的正名点**被 Attach 挡住——羁绊由 pack 薄点 ModifyRule 替位表达（本卡最大的替位注记） |

  转正时建议核对这一非对称。

## 8. 遗留与声明

1. **（上报 1c）撞臂豁免清单见 §4**——G8 阵型协同（synergy_bonus/Attach）与 G2 循环积分
   （round_robin_points/RollCheck）是两个模块**正名口径被未交付臂挡住**的实证：1c 机动卡
   交付 Attach/RollCheck 真渲染时，本样板是现成的验收场景（解除豁免→改选正名选项→重跑全链）。
2. **（上报量产波）MG 迁移承接点跨 pack 复用性缺口**：sys.tactical_board 的 mg0/mg1 四点
   effects 硬编码 `grid.unit_roster`（grid_strategy 保 id 迁移产物），任何第二个引用方都
   不可用。金样重固化窗口并入 TB 正式档时应一并占位符化。
3. **（上报）Rows/Matrix 参数不走 substitute_placeholders**：c0_compile 只对 Scalars
   替换 `{param:}`——表结构选项（如 terrain_cost_pathfind、score_formula_rank）的
   effects_template 裸 entity 无法用占位符路线修复，属基建缺口非数据可修。
4. **（上报）CLI 无 set_not_applicable 通道**：`authoring na` 仅 baseline 理由码跳过，
   人工豁免（理由+说明+署名）只有 engine API——冒烟段因此止步于装配+判定面，
   全链由 e2e 覆盖。CLI 补 `authoring exempt` 后冒烟可延伸全链。
5. **（申报）u.genre 无自走棋选项**：通用层不在本卡可写范围，冒烟段走装配+判定不触
   L2；e2e 用测试内嵌通用层（含 auto_battler 选项）。与 5a 同款缺口。
6. **真 AI 访谈未验证**：数据根无 ai_provider 配置（与 5a M5 同状态），全链走
   ScriptedProvider。补跑路径同 5a 验收单 §6。
7. **并行卡边界**：未触碰 sys.beatmap_timeline 与 rhythm_micro（5c 范围）；未改任何
   src/**、spire_like/grid/ld pack、docs/plan；零 git 操作、零新增依赖。
