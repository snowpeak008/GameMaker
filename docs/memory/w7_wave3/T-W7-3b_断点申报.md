  1. **构造纯函数落 adm4-authoring 新文件 `compose.rs`**：`assess_composition(space, selections, modules, confirmation) -> Adm4Result<Option<CompositionAssessment>>`；`CompositionAssessment { report, missing_tiers, over_reference_line, confirmation }`。refs 空→None（旧项目零开销）。

  3. **成边口径**：每实例 provides 名词→ Provides 边（noun=裸名, to=""）；consumes/modifies 按 noun_bindings 成边——target 是核心名词→noun=核心名词名 to=""（V6 白名单匹配）；target 是 `<提供方>.<名词>`→noun=名词段 to=提供方（与 Provides 边裸名匹配，H 邻接由此建立）。κ 直取 SystemRef.core_link（0c 注释：校验器信任该字段）；core_loop_verbs 留空（L2 结构化动词绑定无数据源，归后续波）；is_meta_only=false（meta 用 κ 声明表达）。
  4. **product_grade**：`u.target_scale` 映射 iaa_hypercasual→HyperCasual/midcore→MidCore/indie→Casual/triple_a→HardCore/large_service→Mmo；未选→HyperCasual 最严（0c 同精神：宁多提示不静默放行）。budget 占位空表。
  5. **tier 未选**：实例不进 input、记 missing_tiers，gate2 产 block `composition_tier_unselected`（任务卡裁决原文）。
  6. **form_confirmed**：`AuthoringState` 加 `composition_form_confirmation: Option<CompositionFormConfirmation{signer,note,at,h_set}>`（serde default+skip 空，I2 零漂移）。assess 内两遍跑 check_composition：probe(form_confirmed=false) 拿 h_set→快照比对→有效再跑 true 版（不复制 is_heavy 判据）。确认不 bump revision（dispose 先例）。
  7. **gate2 合流**：blocks/missing 先入 findings 算 passed，advices+确认待办随后 append（gate1 N/A 先例：在案不拦）。code 形态 `composition.<serde code>` / `composition_advice.<serde code>` / `composition_form_confirmation_required`。
