## 五、内容自评抽点（3 点自证）

1. **sys.scoring_combo.decay_rule（K1 档）**：真问句「连击/倍率的衰减走什么曲线？」；两选项语义有别——断连即归零（无中间态、零参数、压力全给续连窗口）vs 曲线衰减（可挽救警告态、Curve 参数、DMC 风格槽口径），是「悬崖 vs 坡道」的真取舍；曲线选项落 `schema: curve`（任务卡点名的 Curve 好场景），effects 用 `schedule(over_time)` 内嵌 `curve_sample(elapsed_ratio)`，占位与 16 变体 snake_case 合规。
2. **sys.class_archetype.constraint_form（A0 档）**：真问句「安装约束以什么形态声明？」；槽位类型匹配（静态分类学，界面自解释，表达不了跨系统条件）vs 前置谓词检查（动态求值，「须持盾才能释放」的直接表达位，代价是运行时监听与接口耦合）——两选项 implications 各自陈述真实代价，非冲压对照。
3. **sys.onboarding.absence_detection（N2 档）**：真问句「行为缺失按什么口径检测？」；次数窗口（便宜但分不清『不会』与『不想』，误报要豁免位兜）vs 情境错失（「该用而未用」谓词，精准但每条教学要人工写谓词、依赖细粒度事件）——检测精度与内容成本的真实权衡，effects 分别用 roll_check 的 on_failure/on_success 分支表达触发方向差异。
