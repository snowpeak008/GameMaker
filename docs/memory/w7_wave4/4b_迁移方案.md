# T-W7-4b 迁移方案（存量两包拆解迁移 + 25 逆向模板标 smoke_test）

## 一、前任三个结构性发现（执行依据，全文见 T-W7-4b_断点申报.md）

- **发现 A（实例 id 命名空间独占）**：system_loader 重写 = 纯前缀替换
  `<module_id>.` → `<instance_id>.`，且实例 id 包内唯一 → 每包最多一个模块实例能以
  「实例 id = 旧前缀」实现 id 逐字节保持迁移。ld 的 deploy 与 economy 两个可承接域
  不能同时以 `ld` 前缀保 id。
- **发现 B（lane_defense 本卡零迁移）**：任何 system_refs 都会让 `execute_freeze` 把
  非空 `module_versions` 写进冻结哈希载荷 → 金样 `identity.frozen_hash` 必漂移
  （豁免清单固定不许新增）；且 tier 合成点 `ld.tier` 恒 Active 进分母，会破
  cli_smoke 既有断言（访谈回合 5）与冻结完备门。可承接点全部留 pack 本体，
  逐点原因见 `4b_分母对账单.md`；拆解归模块量产波（金样重固化窗口一并做）。
- **发现 C（grid_strategy 可迁）**：无金样、冒烟不冻结该包。迁移集 =
  sys.tactical_board 承接 4 点：`grid.battlefield_system`（L3）/ `grid.move_rule`（L4）/
  `grid.terrain_effect_rule`（L4）/ `grid.terrain_table`（L5），实例 id=`grid` 保 id。

## 二、执行结果

### ① grid_strategy 迁移（已落盘）

**模块侧**（`knowledge/systems/sys.tactical_board/module.json`，semver 1.0.0 → 1.1.0）：

- 新增 4 个决策点，id 带 `sys.tactical_board.` 前缀，语义/选项/参数 schema/
  effects_template 与 pack 原点逐字节等价；选项 `unlocks` 改写为模块前缀形式

  保持字面 `grid.battlefield_system`——加载器只把恰等于 module_id 的标签重写为
  tier 合成点，字面标签在实例 id=grid 下逐字节保持 C0 归属（见「遗留」）。
- 新增两个**迁移承接档**（tier 合成点须 ≥2 选项，validate_graph 的
  insufficient_options 拦单选项非表格点，这是承接档必须是两个的结构原因）：
  - `mg0_migration_base`（rank 0）：activates = battlefield_system + move_rule；
  - `mg1_terrain_carrier`（rank 1）：MG0 + terrain_effect_rule + terrain_table。
  既有 TB0-TB3 各档 activates 前置补入迁移四点，维持「高档递增包含低档」校验；
  迁移点 tier_gate 归 MG0/MG1（activates 递增包含成立）。
- 基数期望 `terrain_types {4,12}` 随 terrain_table 迁入模块（装配时重写为
  `grid.terrain_types`，与 schema 内 cardinality_key 的重写同步，键匹配不断）。
- 涉及迁移四点的 pack 基数期望/一致性规则同步项：仅 terrain_types 一项；
  pack 的 7 条一致性规则均不引用迁移点，零改动。

## 三、「壳 = 组合模板」对应关系说明

迁移后的 grid_strategy pack 呈现目标形态的雏形：**品类包壳 = 「引用哪些系统模块、
各开到哪个档、名词怎么绑定」的组合模板**，而不是决策点的所有权仓库。

- 本卡已就位的对应关系：`system_refs`（引用集）+ `allowed_tiers`（档位窗）+
  `noun_bindings`（名词织网）+ `core_nouns`（包供给的语义锚）——网格/地形四点已由
  「pack 私有」转为「模块供给、壳按档取用」。
- 尚留在壳内的：战斗四点/回合两点（归 #2 回合战斗模块）、波次关卡（归 #7）、
  养成三点（语义非货币，sys.economy 不承接）——它们待对应模块入库后按同一手法拆解。
- **正式类型化归后续波**：当前「壳」仍复用 GenrePack 结构（decision_points 与
  system_refs 并存的过渡态）；「组合模板」作为一等类型（壳自身版本化、
  引用集可比较可继承）待模块量产波与金样重固化窗口一并落。
