- 校验红线：档 id 唯一；五维 0-3；p_floor≤rating.p；interface_floor 不超 C 档边数上界（C0→1 / C1→3 / C2→6 / C3 无上界）；activates 递增包含；点 id 强制 `<module_id>.` 前缀；裸名词本地声明、外部名词带点号。

- 档带边界：轻 0-4 / 中 5-8 / 重 9-12 / 极重 13-15。
- L4 每选项必带非空 effects_template（snake_case tag，`{param:KEY}` 占位）、选项 ≥2、summary 非空。
