## 里程碑 1：形态裁量（申报理由）

- **选独立 crate `tools/spec_diff`**（workspace member，包名 `adm4-spec-diff`，二进制 `spec_diff`），不走 adm4-cli 子命令。
  理由：① `apps/adm4-cli/src/main.rs` 已 151KB 单文件、波 3 并行改动多，避开冲突面；② 4b 需要脚本断言退出码，`cargo run -p adm4-spec-diff --` 即可；③ 只读依赖 `adm4-spec`（不改业务 crate），职责单一。
- 设计要点：
  - 映射表 JSON：`exact`（逐条精确）+ `prefix`（前缀规则，from/to 均须以 `*` 结尾，最长前缀优先）+ `ignore_paths`（豁免路径前缀，风格对齐 golden_diff 豁免清单）；`deny_unknown_fields` fail-closed。
  - 映射施加在旧侧全部字符串（整串匹配 + `section/<id>` SpecRef 尾段形态），覆盖 `system_id`/effects 实体引用/design_notes.source_decision/source_map 等 id 引用位。
  - 段内按 id 建索引比对（BTreeMap 确定序）；两旧 id 映射到同一新 id → 碰撞，退出码 2。
  - 退出码：0=语义零 diff，1=有差异（含 missing/added），2=输入或映射表错误。
