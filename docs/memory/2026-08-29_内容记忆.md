## 3. 代码产出

### adm4-template（T3，逆向产线）
- `corpus.rs`（新）：`FileCorpusChannel` 本地语料检索——快照约定 `<目录>/<game_name>/*.json`（EvidenceCandidate 数组），关键词大小写不敏感匹配 title/snippet，URL 去重排序，零网络。

- `library.rs`：`human_review` / `certify`（先登记 `SkinWordlist` 后落盘模板）/ `approved_for_prefill`（只放行 Certified）。

- 签名变更：`certify` 改收 `&mut Template`；`Template::is_approved()` 语义 = Certified。
- 新增依赖 adm4-ai（workspace）；7 个测试（全链正例 + 跳级/无证据负例 + R7 四变体等）。
