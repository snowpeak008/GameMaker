# Fixplan 问题与解决方案记录

本目录是 AutoDesignMaker 二次开发期间的跨窗口统一问题记录区。

## 记录约定

- 当前窗口和其他窗口发现的问题、根因、解决方案、验证结果，都记录在本目录。
- 一个相对独立的问题使用一个 Markdown 文件，避免不同窗口同时追加同一个长文件产生冲突。
- 文件名建议使用 `YYYY-MM-DD_NNN_<short-slug>.md`；编号按目录内当天已有记录递增。
- 记录不得包含 API 密钥、访问令牌或其他敏感配置。

## 推荐内容

```markdown
# 问题标题

## 问题

## 复现条件

## 根因

## 解决方案

## 验证

## 后续事项

## 来源
```

同一问题后续再次修复时，优先更新原记录，并在“验证”或“后续事项”中补充新的结果。
