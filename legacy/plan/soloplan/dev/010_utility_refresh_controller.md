# 010 工具面板刷新控制器

## 目标

将工具面板从“每次切换全量刷新”改为按目标刷新，并阻止异步旧响应覆盖较新状态。

## 原子工作

1. 在 `utility-panels.js` 增加持久控制器，目标集合固定为 patch/package/logs/sdk/save。
2. 每个目标维护独立、单调递增的请求代次；只有当前代次允许渲染。
3. SDK 的列表和批准上下文作为同一目标并行读取、原子提交。
4. 提供 `refresh(target)` 与 `refreshAll()`；保留 `initUtilityPanels` 兼容包装。
5. `main.js` 初始化时执行一次全量加载；后续任务页签切换只刷新对应目标。
6. 存档加载后继续刷新需要同步的全部运行时视图，不改变现有保存事务顺序。
7. 增加测试：目标调用计数、并行目标隔离、旧响应丢弃、错误结果提交及全量返回结构。

## 验收

- 点击日志页只调用日志读取，不读取补丁、打包、SDK 或存档。
- 同一目标的较慢旧请求不能覆盖较快新请求。
- 保存/加载工作流仍能同步设计、流水线、AI、工具和 Shell 状态。

## 实施结果（2026-07-14）

状态：**已完成**。新增 `createUtilityPanelsController`、`refresh(target)` 和 `refreshAll()`；SDK 双请求原子提交，各目标使用独立代次拒绝旧响应。测试确认日志页只读取日志、竞态响应不覆盖新状态、失败状态可提交且全量返回结构兼容。
