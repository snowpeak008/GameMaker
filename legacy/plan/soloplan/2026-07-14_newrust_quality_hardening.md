# NEWrust 质量加固与界面一致性开发计划

## 背景

2026-07-14 全局审查确认 NEWrust 的 Rust 全工作区测试、前端测试、双语门禁、90 张 UI 截图、93 条 UI 基线、独立性边界和根启动器检查均通过，但仍存在以下工程问题：

- 设计工作台、AI 访谈和工具面板将后端读取失败降级为空数据，用户无法区分空项目与运行时故障。
- 工具页签每次切换都会并行刷新全部工具子系统，没有请求代次控制，存在重复 IPC 和旧响应覆盖风险。
- UI 门禁在 Playwright 不可用时静默降级到无超时的系统 Chrome，同步截图可能永久挂起，且跳过 DOM/fixture/响应式断言。
- 默认空白启动会创建新的桌面草稿；现有 `pruneDraftsKeepCount` 只有契约字段，没有安全的执行策略。
- Shell 状态采用固定 `setInterval`，窗口隐藏或前一次请求未结束时仍可能继续排队。
- AI 配置使用未定义的 `.secondary-button`，窄屏任务导航缺少明显的横向可发现性。
- 前端多个大模块重复维护 `read/asArray/clear/el`，Clippy 仍产生大量低价值警告。

## 约束

1. 不修改游戏设计内容、103 节点结构、Step00-14 业务定义、存档语义或 IPC 命令名称。
2. 不读取父级 Python 项目的运行时数据、配置、Schema 或资源。
3. 不删除正式存档、非空草稿、活动草稿、事务目录、恢复草稿或未知文件布局。
4. 草稿保留默认继续关闭；只有显式配置后才允许清理，且仅清理可证明为空白并已解锁的旧桌面会话。
5. 保留现有公开 JavaScript 导出和 Tauri 命令兼容面，结构整理以内部复用为主。
6. 当前工作树包含上一轮空白启动和根 EXE 改动，所有实现必须在其上增量开发，不覆盖或回退。

## 目标

1. 所有初始读取失败均显示稳定、双语、可重试的失败状态。
2. 工具面板按目标页签刷新，并通过独立请求代次拒绝过期响应。
3. UI 门禁只接受完整 Playwright 语义检查，任何依赖或浏览器故障都快速失败并可靠释放资源。
4. 激活已有草稿保留契约，提供默认关闭的安全空白草稿清理策略和完整测试。
5. Shell 轮询不重入、窗口隐藏时暂停，并可在重新可见时立即刷新。
6. 统一 AI 配置按钮和键盘焦点样式，增强窄屏导航可发现性。
7. 提取无业务含义的前端公共值/DOM 工具，降低重复代码而不改变渲染结果。

## 开发顺序

1. 先建立显式加载错误模型和测试，保证后续刷新重构有稳定错误契约。
2. 再建立工具面板刷新控制器，按目标加载并阻止过期响应提交。
3. 修复 UI 门禁的 fail-closed、超时和 finally 清理边界。
4. 新增独立草稿保留模块，接入运行时、Shell 契约和文档。
5. 将 Shell 固定间隔改为非重入、可见性感知调度器。
6. 统一 UI 控件样式并提取前端公共小工具。
7. 执行全量格式、静态检查、测试、双语/UI/独立性门禁和启动器检查。

## 完成标准

- 后端读取失败不再显示“等待数据”或空记录，设计、AI、补丁、打包、日志、SDK 和存档均有明确错误状态。
- 快速切换工具页签不会让旧请求覆盖新状态；单页签切换只读取该页签所需数据。
- 缺少 Playwright 时 `ui-gate` 在启动服务器前失败；浏览器/断言异常后没有残留 Node/Chrome 进程。
- `pruneDraftsKeepCount=0` 继续表示不清理；显式正整数只保留最近 N 个符合安全条件的空白旧草稿。
- Shell 刷新同一时间最多一个请求，隐藏窗口不继续轮询。
- 双语桌面、紧凑和窄屏截图无裁切、重叠或原生未样式化按钮。
- Rust workspace、Web checks、独立性边界和根启动器检查全部通过。

## 实施结果（2026-07-14）

状态：**已完成开发态实现与验证**。

1. 009-010：设计、AI 访谈和五类工具面板均保留真实加载失败；工具面板支持按目标刷新、独立请求代次和过期响应丢弃。
2. 011：UI 门禁已移除系统 Chrome 弱化路径，Playwright 缺失、启动失败或页面超时均 fail-closed，并在 `finally` 中回收浏览器和静态服务器。
3. 012：新增默认关闭的安全空白草稿保留模块；只处理精确匹配、未绑定、非活动、已解锁且内容等于规范空白状态的旧桌面草稿。
4. 013：Shell 改为请求完成后再调度，隐藏窗口暂停，恢复可见立即刷新，同一时刻最多一个 Shell 请求。
5. 014：补齐次级按钮、键盘焦点和窄屏任务导航样式，并提取无业务语义的共享值/DOM 工具。
6. 015：Rust workspace check/test、Web build/unit/e2e、双语与 UI 门禁、独立性边界、根 EXE 检查以及根/便携 smoke 均通过；90 张 UI 截图和 93 条 UI baseline 通过。本轮源码已重新构建为便携开发快照，根 EXE 实际委托到该新版本。

普通 Clippy 通过，但工作区 `-D warnings` 仍会被本轮前已有的风格警告拒绝；本轮新增草稿模块无新增 Clippy 警告。正式发布门禁仍需在用户提交累计改动后，从干净工作树重新运行 `tools/verify-standalone.ps1`，本轮不绕过该门禁。
