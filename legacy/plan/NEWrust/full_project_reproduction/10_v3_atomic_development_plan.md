## 3. Batch Rules

- Each atom must update implementation, tests, and documentation in the same or immediately adjacent change.
- Each atom must mention the Python source files it closes, using `03_file_disposition_matrix.md` as the source of truth.
- If an atom discovers a missing source file or asset category, stop implementation and update inventory/mapping/scorecard first.
- Atoms that introduce new CLI commands must add `--help`/argument validation tests.
- UI atoms cannot be marked done without the states listed in `07_ui_python_baseline_plan.md`.
- Data atoms cannot be marked done without loader tests against real asset files.
