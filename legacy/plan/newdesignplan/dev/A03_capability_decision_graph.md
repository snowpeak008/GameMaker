# A03 能力决策图与持续反过拟合门禁

状态：已完成（2026-07-15，本地实现，按用户要求待总验收后提交）
依赖：A02

## 目标

用能力谓词生成动态决策图，取代类型标签硬分支；建立此后每个编译器任务都必须携带的第二层反过拟合测试。

## 变更

1. 决策图由能力谓词激活（`spatial.topology`、`time.progression`、`control.cardinality`、`content.generation`、`participants.mode` 等）；类型/题材标签只用于检索与展示。
2. 激活结果携带完整理由（哪个谓词、哪个规格字段触发）。
3. 原 16 领域/103 节点/515 清单项作为激活感知知识库接入：命中谓词且存在未满足约束才激活；未激活不拉低完成度。
4. **第二层反过拟合测试基建**（此后 A06–A08 每个编译器任务复用）：
   - 标签置换测试工具：样例类型标签替换为无意义字符串，断言输出语义不变；
   - 能力扰动测试工具：改变一个能力谓词，断言输出相应变化。

## 验收（停止门）

- 相同规格重复生成决策图结果一致（确定性）。
- 四个 A01 样例产生结构不同的激活集，且每项激活可追踪到谓词。
- 标签置换与能力扰动测试对决策图本身通过。
- 核心源码扫描无类型名分支。

## 回滚

删除决策图模块与测试工具 crate/模块；知识库数据不受影响。

## 实际结果

- 在 `NEWrust/crates/adm-new-design/src/decision_graph/` 新增能力决策图编译器和版本化策略边界；编译器读取既有 16 个域，不改写 `knowledge/design_data/domains/` 的任何知识数据。
- 现有 16 域 / 103 节点 / 515 检查项全部进入策略覆盖校验。未知域、失效条件引用、未知覆盖项、空检查项和硬依赖环均 fail closed，并返回稳定错误代码、路径和修复建议。
- 每个活动节点携带谓词 ID、`/capabilities/...` JSON Pointer、运算符、期望值和实际值；仅能力相关且仍有未满足检查项的节点进入活动图。能力不相关节点不进入完成度分母，已满足节点保留为相关但从活动图退出。
- 在 `NEWrust/crates/adm-new-design/src/anti_overfit.rs` 提供覆盖完整 `CapabilityProfile` 16 个轴的单能力扰动工具，以及仅改检索/展示字段的标签置换工具，供 A06–A08 编译器任务复用。
- 四个 A01 样例的激活集合两两不同；相同输入重复编译及序列化字节一致；标签置换后决策图完全相同；单一参与者能力变更会改变激活集合并留下对应字段证据。
- `cargo fmt --all -- --check`、`cargo check --workspace --locked` 通过；`adm-new-design` 共 48 项测试通过。安全自检通过（4 条规则、418 个命中、151 个精确例外），4 个新增源码/测试文件补充扫描为 0 命中。
- 独立性边界扫描通过（245 个文件、父项目/Python 禁止引用 0）。本任务未接入现有 UI 或 D1–D4 运行路径；接入按 A06 执行。
