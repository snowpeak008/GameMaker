# 05 Step09 美术任务合同兼容扩展

## 目标

向后兼容扩展既有 `art_production_task_contract.schema.json`，让 Step09 生成面向可消费资产的美术生产任务。

## 修改范围

```text
knowledge/schemas/ai_design/art_production_task_contract.schema.json
core/art_pipeline/contracts/art_task_contract.py
pipeline/step_09_art_plan/plugin.py
core/tests/unit/test_step09_art_task_contract.py
```

## 兼容规则

保留既有 required 字段：

```text
task_id
asset_id
unity_target_path
dimensions
consumer_system
mount_point
acceptance
```

新增字段优先 optional：

```text
generation_prompt
negative_prompt
semantic_policy
slice_spec_ref
unity_import_policy_ref
target_mount_ref
required_variants
acceptance_criteria
rework_policy
source_refs
```

## 输入

- Stage04 asset specs
- Stage04 unity import policy
- Stage04 slice specs
- Stage07 style confirmation

## 输出

```text
outputs/artifacts/stage_09/art_production_task_contract.json
```

## 验收标准

- 旧字段仍存在并保持语义。
- P0/P1 task 缺 prompt、negative prompt 或 acceptance criteria 时 blocked。
- 每个 task 有 Stage02/04 source refs。
- 任务描述不能停留在“生成一个 UI 图片”。

## 禁止事项

- 不新建重复 schema。
- 不删除或重命名既有字段。
- 不把新字段直接设为 required，除非同步迁移旧输出和测试。
