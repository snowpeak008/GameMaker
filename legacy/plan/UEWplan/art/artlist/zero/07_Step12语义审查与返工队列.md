# 07 Step12 语义审查与返工队列

## 目标

把“看起来不像可用资产”的问题转成可追踪返工项，同时避免在没有 Vision AI 时假装完成视觉识别。

## 修改范围

```text
core/art_pipeline/services/semantic_validator.py
core/art_pipeline/services/rework_queue.py
pipeline/step_12_art_production/plugin.py
core/tests/unit/test_art_pipeline_semantic_rework.py
```

## 输入

- `raw_generated_asset_manifest.json`
- `image_quality_report.json`
- Stage04 semantic policy
- Stage09 art task prompt / negative prompt

## 输出

```text
outputs/artifacts/stage_12/art_semantic_review_report.json
outputs/artifacts/stage_12/art_rework_queue.json
```

## 第 1 层：Deterministic 检查

无外部依赖，必须实现。

检查：

- 文件名。
- 文件路径。
- metadata。
- `asset_kind`。
- prompt / negative prompt。
- non-consumable markers。

阻断 marker：

```text
_concept
_reference
_moodboard
_draft
_wip
copyright
watermark
```

## 第 2 层：视觉内容审查

需要 Vision AI 或人工审查。

未接入 Vision AI 时：

- 状态写 `needs_human_review` 或 `vision_review_unavailable`。
- 不写 passed。
- `semantic_policy.requires_visual_review=true` 时 Step12 为 `completed_with_review`。

## 验收标准

- P0/P1 命中 deterministic marker 时 blocked 或 completed_with_review。
- 视觉检查不可用时不会假成功。
- rework queue 包含 asset_id、issue、repair prompt 建议、source refs。

## 禁止事项

- 不用简单像素启发式冒充视觉识别。
- 不让视觉检查缺失时报告 passed。
- 不让 unresolved rework queue 被 Step13 绕过。
