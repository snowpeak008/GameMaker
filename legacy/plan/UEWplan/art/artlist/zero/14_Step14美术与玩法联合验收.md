# 14 Step14 美术与玩法联合验收

## 目标

证明 Unity 项目不是空屏，而是有真实 UI、交互、状态推进和上层设计需求覆盖。

## 修改范围

```text
core/art_pipeline/services/art_acceptance.py
pipeline/step_14_integration_validation/plugin.py
core/tests/unit/test_step14_art_acceptance_contract.py
```

## 输入

- Stage13 reports。
- Stage02 playable/ui contracts。
- Stage03 program requirements。
- Stage04 asset contracts。
- Step14 integration validation report。

## 输出

```text
outputs/artifacts/stage_14/art_acceptance_report.json
outputs/artifacts/stage_14/playable_acceptance_report.json
outputs/artifacts/stage_14/screenshots/
```

## 验收层级

| 层级 | 内容 | 失败状态 |
|---|---|---|
| Level 1 | artifact、source_refs、asset_id、binding_id 完整 | blocked |
| Level 2 | Importer、Sprite、Atlas、Prefab、SerializedField 正常 | failed |
| Level 3 | 首屏 UI 可见、按钮可点击、状态变化 | failed |
| Level 4 | 截图/像素检查不是黑屏、空屏、全透明 UI | failed / environment_blocked |
| Level 5 | Stage02/03/04 上层设计需求被覆盖 | failed / skipped_with_warning |

## Level 4 阈值

- 非透明像素比例 >= 5%。
- active enabled Unity UI `Graphic` >= 1。
- 失败截图：`outputs/artifacts/stage_14/screenshots/fail_<check_id>.png`。
- PNG 格式。
- 优先 1920x1080，否则记录实际分辨率。

报告字段：

```text
check_id
screenshot_path
resolution
non_transparent_ratio
active_graphic_count
source_refs
```

## Level 5 来源

- `playable_acceptance_contract.playmode_checks`
- `ui_flow_contract.playmode_checks`
- `program_requirements_contract.tasks[].acceptance`
- `asset_spec_contract.assets[].acceptance_check`
- `asset_registry.assets[].purpose`

## 验收标准

- 首屏没有 enabled Graphic 时 failed。
- Button action 不触发时 failed。
- Data binding 无变化且设计要求变化时 failed。
- 上层验收来源存在但未覆盖时 failed。
- 上层验收来源缺失时 skipped_with_warning。

## 禁止事项

- 不把 Unity 不可用当作 passed。
- 不只验证 GameObject 存在。
- 不跳过截图失败证据归档。
