# 04 Step04 资产消费规格

## 目标

让 Step04 不只输出资产列表，而是输出可生产、可加工、可挂载、可绑定的资产消费规格。

## 修改范围

```text
core/art_pipeline/contracts/image_consumable_spec.py
core/art_pipeline/contracts/ui_slice_spec.py
core/art_pipeline/contracts/unity_import_policy.py
pipeline/step_04_art_requirements/plugin.py
core/engines/generation.py
core/tests/unit/test_step04_asset_consumable_specs.py
```

`core/engines/generation.py` 只允许兼容层调用，不新增美术业务逻辑。

## 输入

- Stage02 `ui_flow_contract`
- Stage02 `playable_acceptance_contract`
- Stage03 `program_requirements_contract`
- Stage04 `asset_spec_contract`
- Stage04 `asset_registry`

## 输出

```text
outputs/artifacts/stage_04/image_consumable_spec.json
outputs/artifacts/stage_04/ui_slice_spec_contract.json
outputs/artifacts/stage_04/unity_import_policy.json
outputs/artifacts/stage_04/asset_usage_binding_seed.json
outputs/artifacts/stage_04/audio_placeholder_requirements.json
```

## 实现要点

- 为每个 P0/P1 asset 生成技术规格和语义规格。
- 为 UI control 生成切片规格或明确豁免理由。
- 为 Unity import 生成 PPU、pivot、sprite mode、alpha、compression 策略。
- 所有 `unity_target_path` 以 `Assets/AutoDesign/` 为根。
- 音频只生成占位需求，不生成真实音频。

## 验收标准

- P0/P1 asset 无规格时 Step04 不能成功。
- UI button 不能默认整图放行，必须有状态图、九宫格或 fallback 策略。
- 不输出 `Assets/Art/...` 或 `Assets/Prefabs/...`。
- schema validator 通过。

## 禁止事项

- 不在 Step04 生成真实图片。
- 不把图片可消费性留到 Step13 才判断。
- 不硬编码具体游戏类型。
