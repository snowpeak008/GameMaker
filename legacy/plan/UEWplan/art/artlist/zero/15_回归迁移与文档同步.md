# 15 回归迁移与文档同步

## 目标

完成回归测试、legacy 文档治理、记忆同步和实现收尾，防止新旧 art 计划形成双系统。

## 修改范围

```text
core/tests/
plan/UEWplan/art/
knowledge/ai_memory/
```

## 执行步骤

1. 运行回归：

```powershell
python -m pytest core/tests/ --tb=short -q
```

2. Unity 可用时运行 batchmode 流程：

```powershell
Unity.exe -batchmode -projectPath <generated_unity_project> -quit -logFile compile.log
Unity.exe -batchmode -projectPath <generated_unity_project> -executeMethod AutoDesignAssetImporter.Run
Unity.exe -batchmode -projectPath <generated_unity_project> -executeMethod AutoDesignPrefabBuilder.Run
Unity.exe -batchmode -projectPath <generated_unity_project> -executeMethod AutoDesignSceneBinder.Run
```

3. 治理 legacy 文档：
   - `art/01-07` 增加 Legacy 说明，或移动到 legacy 目录。
   - `00` 索引确认以 `08/09/10/artlist/zero` 为准。

4. 同步记忆：
   - 记录核心实现边界。
   - 记录测试结果。
   - 记录仍需人工/Unity 环境验收的项。

## 验收标准

- 新增/修改测试通过，或有明确 environment_blocked 说明。
- 旧口径“只生成规格、不实际执行、失败不阻断、像素检查可选”不再作为实现依据。
- 文档索引指向原子计划。
- 没有新增具体游戏类型硬编码。

## 禁止事项

- 不把 plan-only 文件误当运行时代码完成。
- 不提交无关历史清理。
- 不跳过最终 `git status` 和 diff 审查。
