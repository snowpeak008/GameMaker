# 08 Step12 资产归档与切片元数据

## 目标

生成 Unity 可消费的资产拷贝/命名结果和 Sprite 切片元数据。Python 不做实际像素切割；实际 Sprite 切割由 Step13 Unity Editor Script 执行。

## 修改范围

```text
core/art_pipeline/services/asset_normalizer.py
core/art_pipeline/services/sprite_slicer.py
pipeline/step_12_art_production/plugin.py
core/tests/unit/test_art_pipeline_sprite_slicer.py
```

## 输入

- `raw_generated_asset_manifest.json`
- `image_quality_report.json`
- Stage04 `ui_slice_spec_contract.json`
- Stage04 `unity_import_policy.json`

## 输出

```text
outputs/artifacts/stage_12/processed_asset_manifest.json
outputs/artifacts/stage_12/sprite_slice_result_manifest.json
```

## 职责边界

Python Phase 07/08：

- 复制或重命名图片。
- 登记 processed asset path。
- 生成 slice metadata。

禁止：

- 不执行像素切割。
- 不 resize。
- 不 crop。
- 不 trim。
- 不 pad。
- 不重新编码图片。
- 不把 Pillow 作为本阶段依赖。

Unity Phase 11：

- 读取 `sprite_slice_result_manifest.json`。
- 通过 `TextureImporter` / `SpriteMetaData` / reimport 应用切片。

## Metadata 必需字段

```text
sprite_id
rect
border
pivot
pixels_per_unit
fallback_sprite_id
source_refs
```

## 验收标准

- button 至少有 normal、pressed、disabled。
- highlighted 缺失时有 fallback。
- nine_slice 四向 border 非空。
- 输出 metadata manifest，测试证明 Phase 11 可消费。

## 禁止事项

- 不在 Python 中实现 Unity SpriteEditor 等价逻辑。
- 不静默处理真实像素修复需求；需要时写入 rework queue。
