# 图像规格校验合同（Step04-Art-A）

## 目标

在 AI 生成图像进入 Step12（美术生产）之前，建立机器可校验的图像规格标准，区分"可消费资产"与"概念图/气氛图"。

## 问题根因

现有 `asset_spec_contract.json` 中每个资产有 `dimensions`、`background`、`acceptance_check` 字段，但这些字段是生成规格，不是验收校验。没有任何代码实际检查 AI 输出图片是否满足这些规格。

## 校验规则分类

### 按资产类型的默认规格

| 资产类型 | 推荐尺寸 | 必须透明 | 视角 | 命名规则 |
|---------|---------|---------|------|---------|
| `button` | 256×64 ～ 512×128 | 是 | screen_space_ui | `btn_[name].png` |
| `panel_background` | 512×512 ～ 1920×1080 | 否（可不透明） | screen_space_ui | `bg_[name].png` |
| `icon` | 64×64 ～ 256×256 | 是 | icon_flat | `icon_[name].png` |
| `hud_element` | 128×32 ～ 512×128 | 是 | screen_space_ui | `hud_[name].png` |
| `nine_slice` | 64×64 ～ 256×256 | 是 | screen_space_ui | `9s_[name].png` |
| `environment_tile` | 64×64 或 128×128（2的幂） | 视情况 | top_down_orthographic | `tile_[name].png` |
| `character_sprite` | 128×128 ～ 512×512（2的幂） | 是 | any | `char_[name].png` |
| `effect_sprite` | 128×128 ～ 512×512 | 是 | any | `fx_[name].png` |

### 不可消费资产识别标志（non_consumable_markers）

文件名或 metadata 中含有以下词时，标记为 `non_consumable`：
- `_concept`、`_reference`、`_moodboard`、`_draft`、`_wip`
- `_decision`（来自 design 节点名）
- 尺寸非 2 的幂次且为 UI 类型时
- 包含文字水印或 copyright 标记

## 执行步骤

1. 定义 `image_spec_validation_contract.schema.json`。
2. 在 `core/art_pipeline/image_spec_validator.py` 中实现：
   - `build_image_spec_validation_contract(asset_registry, asset_spec_contract) -> dict`
   - `validate_image_against_spec(image_path, spec) -> ValidationResult`（可选，运行时才用）
3. Step04 在输出 `asset_registry.json` 后，同步生成 `image_spec_validation_contract.json`。
4. Step12（美术生产）读取 `image_spec_validation_contract.json`，对已生成图像做静态规格检查：
   - 文件名是否符合 `naming_pattern`
   - 是否包含 `non_consumable_markers`
   - 基本尺寸记录（实际像素检查可选，需 Pillow 或类似库）
5. 不通过校验的资产标记为 `validation_status: failed`，Step12 报告中记录，不阻断整体但提醒。
6. 纯占位资产（`audio_placeholder`、`fallback`）豁免校验。

## 完成标准

1. Step04 输出包含 `image_spec_validation_contract.json`。
2. 每个非占位资产有对应的校验规格条目。
3. `non_consumable_markers` 检查覆盖至少：`_concept`、`_reference`、`_draft`。
4. Step12 报告中有校验结果摘要（passed/failed/skipped 计数）。
5. 单元测试：`test_image_spec_validator.py` 覆盖命名校验和 marker 检测。

## 不做事项

- 不做实时像素级分析（不依赖 OpenCV/Pillow 作为必选依赖）。
- 不自动删除不合规图像。
- 不阻断整体流水线（警告而非硬阻断，但记录在报告中供 Step14 验收时判断）。
