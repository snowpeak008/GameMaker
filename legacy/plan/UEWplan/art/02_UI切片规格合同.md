# UI 切片规格合同（Step04-Art-B）

## 目标

为每类 UI 图像定义机器可读的切片规格，让 Step12 和后续工具知道：
- 这张图要不要切片
- 怎么切（九宫格/精灵帧/整图）
- 切完的子图叫什么名字、放在哪个路径

## 问题根因

现有流水线生成了 `asset_spec_contract.json`（列出需要哪些资产），但没有定义每个资产的切片方式。Unity 接收到一整张 UI 图后，仍需手动配置 SpriteEditor 切片，导致 Prefab 无法自动拼装。

## 切片模式规则

### `whole`（整图，不切片）
适用于：背景图、全屏 UI、独立图标。
Unity 配置：`Sprite Mode = Single`，不打开 SpriteEditor。

### `nine_slice`（九宫格）
适用于：按钮、面板框、弹窗背景。
Unity 配置：
- `Sprite Mode = Single`
- 在 SpriteEditor 中设置 Border（left/right/top/bottom 像素）
- 使用时设置 `Image.type = Sliced`

示例（按钮）：
```json
{
  "slice_mode": "nine_slice",
  "nine_slice_borders": { "left": 20, "right": 20, "top": 12, "bottom": 12 }
}
```

### `individual_sprites`（命名区域切割）
适用于：一张图包含多个小图标/按钮状态（Normal/Hover/Pressed/Disabled）。
Unity 配置：`Sprite Mode = Multiple`，SpriteEditor 按矩形切割并命名。

示例（按钮状态图）：
```json
{
  "slice_mode": "individual_sprites",
  "named_sprites": [
    { "name": "btn_normal",   "rect": { "x": 0,   "y": 0,  "w": 200, "h": 60 } },
    { "name": "btn_hover",    "rect": { "x": 0,   "y": 60, "w": 200, "h": 60 } },
    { "name": "btn_pressed",  "rect": { "x": 0,   "y": 120,"w": 200, "h": 60 } },
    { "name": "btn_disabled", "rect": { "x": 0,   "y": 180,"w": 200, "h": 60 } }
  ]
}
```

### `sprite_sheet_grid`（等格切割）
适用于：角色动画帧、特效帧。
Unity 配置：`Sprite Mode = Multiple`，SpriteEditor 按固定格子切割。

## 从 `ui_flow_contract` 生成切片规格的规则

```python
def build_ui_slice_spec_contract(ui_flow_contract, asset_registry):
    slices = []
    for screen in ui_flow_contract.get("screens", []):
        for panel_id in screen.get("panels", []):
            asset = find_asset_by_usage(asset_registry, panel_id)
            if asset["asset_type"] in {"panel_background", "window"}:
                slices.append({
                    "asset_id": asset["asset_id"],
                    "slice_mode": "nine_slice",
                    "nine_slice_borders": default_nine_slice_borders(asset),
                    ...
                })
        for control in screen.get("controls", []):
            if control.get("type") == "button":
                slices.append({
                    "asset_id": control["asset_id"],
                    "slice_mode": "individual_sprites",
                    "named_sprites": button_state_sprites(control),
                    ...
                })
    return slices
```

## 执行步骤

1. 定义 `ui_slice_spec_contract.schema.json`。
2. 在 `core/art_pipeline/ui_slice_spec_builder.py` 实现：
   - `build_ui_slice_spec_contract(ui_flow_contract, asset_registry) -> dict`
   - 按资产类型自动推断切片模式（见上表）
   - 九宫格 border 按尺寸 20% 原则默认计算（可被 designNote 覆盖）
3. Step04 在输出 `asset_registry.json` 后，同步生成 `ui_slice_spec_contract.json`。
4. Step12 读取 `ui_slice_spec_contract.json` 生成 Unity `.meta` 文件中的 SpriteEditor 配置片段。
5. Step13 读取切片规格，为每个 `nine_slice` 资产生成 `Image.type = Sliced` 的 Prefab 配置。

## 完成标准

1. Step04 输出 `ui_slice_spec_contract.json`。
2. 每个 UI 类型资产有对应切片模式（不允许默认 `whole`，除非明确声明为背景）。
3. `nine_slice` 条目有具体 border 值（4个方向均非零）。
4. `individual_sprites` 条目有至少 `normal` 状态 sprite。
5. 单元测试覆盖：button → individual_sprites，panel → nine_slice，background → whole。

## 不做事项

- 不实际执行像素切割（只生成规格 JSON，由 Unity Editor Script 或 .meta 文件消费）。
- 不为音频资产生成切片规格。
- 不硬编码任何特定游戏类型的 UI 布局。
