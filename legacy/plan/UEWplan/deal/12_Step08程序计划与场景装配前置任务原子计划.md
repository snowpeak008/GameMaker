# Step08程序计划与场景装配前置任务原子计划

## 目标

让流水线 Step08 按现有职责生成程序开发计划，同时把 playable contracts 中的场景、UI、输入和目标要求转化为 Step11/13 可执行任务。

注意：当前代码中 Step08 对应 `pipeline/step_08_design_to_plan` 和 `stage_08.program_plan_bundle`，不是实际 Unity 场景装配。实际装配仍在 Step13。

## 必须生成的任务类别

- RuntimeBootstrap。
- GameState。
- CameraRig。
- EventSystem。
- Canvas/UIRoot。
- 初始 HUD。
- InputRouter。
- ObjectiveTracker。
- 初始可见对象。
- PlayMode/TestHook。

## 执行步骤

1. 加载 Stage02 playable contracts。
2. 加载 Step03 程序需求。
3. 加载 Step05 程序审查结果。
4. 根据 `scene_bootstrap_contract` 生成场景装配任务。
5. 根据 `ui_flow_contract` 生成 UI runtime 任务。
6. 根据 `core_playable_contract.action_verbs` 生成输入任务。
7. 根据 `demo_flow_contract` 生成目标推进任务。
8. 根据 `playable_acceptance_contract` 生成测试 hook 任务。
9. 输出可被 Step10/11/13 消费的结构化计划。

## 完成标准

1. 缺 `scene_bootstrap_contract` 时 Step08 blocked。
2. 缺 `ui_flow_contract` 时 Step08 blocked。
3. 缺输入动作时 Step08 blocked。
4. 缺目标推进时 Step08 blocked。
5. 输出能被 Step10/11/13 消费。

## 不做事项

- 不直接写 Unity 场景文件。
- 不执行 PlayMode 测试。
- 不生成真实美术资源。
