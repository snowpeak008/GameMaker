# 07 Step04 美术分类与资产策略

## 目标

从 Project DNA 和 archetype asset templates 生成项目专属美术分类、资产策略和音频占位需求，避免 Step04 只输出通用 placeholder。

---

## 分类要求

至少覆盖：

1. 角色/单位。
2. 场景/空间。
3. UI/HUD。
4. 图标/资源。
5. 反馈/VFX。
6. 状态变化。
7. 音频占位事件。

资产来源分层：

| 层级 | 说明 |
|---|---|
| 基础资产 | UI placeholder、fallback visual、audio placeholder，只能作为 fallback |
| archetype 资产 | tower_defense/narrative_puzzle 等最低可玩资产 |
| 决策驱动资产 | 来自 Project DNA core_entities/ui_surfaces/resources/objectives |

---

## 门禁

| Code | 中文描述 | 阻断 |
|---|---|---|
| `ASSET_TAXONOMY_UNDERCOVERED` | 资产分类覆盖不足 | 是 |
| `CORE_ENTITY_WITHOUT_ASSET_STRATEGY` | 核心实体没有资产策略 | 是 |
| `PLACEHOLDER_AS_FINAL` | 占位符被标记为最终资产 | 是 |

---

## 验收标准

1. 两个不同项目 Step04 资产分类明显不同。
2. 核心实体都有资产策略。
3. placeholder 不计入核心资产 fully covered。
4. 音频只输出占位和事件映射，不声明真实音频已完成。
5. UI 资产包含 slice/prefab/import 策略需求。
