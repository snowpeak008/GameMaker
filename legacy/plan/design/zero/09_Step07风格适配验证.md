# 09 Step07 风格适配验证

## 目标

校验风格选择是否适配 archetype、商业模式、平台、受众和可读性，避免不兼容风格直接 approved。

---

## 修改范围

修改：

```text
pipeline/step_07_art_style_generation/plugin.py
core/engines/generation.py
```

新增：

```text
core/design/style_fit.py
core/tests/unit/test_style_fit_validator.py
```

---

## 输出产物

```text
stage_07/style_fit_report.json
stage_07/style_risk_acknowledgement.json
stage_07/customization_score_report.json
```

---

## 规则

1. 从 archetype JSON 读取 `style_compatibility`。
2. 结合 profile 的商业模式、平台、受众校验。
3. 不兼容风格不能直接 `approved`。
4. 用户强制覆盖必须写 `override_reason`。
5. `style_confirmation.json` 的既有 approved 门禁保留，不被替换。

---

## 门禁

| Code | 中文描述 | 阻断 |
|---|---|---|
| `STYLE_ARCHETYPE_MISMATCH` | 风格与游戏类型冲突 | 是，除非有人工覆盖理由 |
| `STYLE_READABILITY_RISK` | 风格存在可读性风险 | 否，warning |
| `STYLE_OVERRIDE_REASON_MISSING` | 强制覆盖缺少理由 | 是 |

---

## 验收标准

1. `tower_defense + cinematic_realism` 默认不能 approved。
2. 推荐替代风格来自 archetype 数据，不硬编码在 UI。
3. 人工覆盖理由写入 `style_risk_acknowledgement.json`。
4. 现有 `style_confirmation.json` 仍能被后续 Step09 消费。
