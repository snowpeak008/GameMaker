# 01 基线诊断与质量扫描器

## 目标

建立一个只读质量扫描器，量化当前 Step00-10 的设计语义问题，作为后续开发的回归基线。

---

## 修改范围

新增：

```text
tools/validators/design_semantic_quality.py
core/tests/unit/test_design_semantic_quality.py
```

不得修改：

```text
saves/
drafts/
pipeline stage outputs
```

---

## 扫描能力

扫描器输入：

```text
python tools/validators/design_semantic_quality.py --artifacts-root <outputs/artifacts>
```

扫描指标：

| 指标 | 说明 |
|---|---|
| `nullish_field_ratio` | 关键合约空字段比例 |
| `generic_task_ratio` | Step08 通用任务比例 |
| `placeholder_asset_ratio` | Step09 placeholder 资产比例 |
| `project_keyword_downstream_rate` | 项目关键词进入 Step03/04/08/09/10 的比例 |
| `template_leakage_count` | Hades、reference template 等残留文本数量 |
| `source_ref_cross_context_count` | source refs 跨 draft/project_signature 风险 |
| `stage_score` | 每步 0-10 质量分 |

---

## 输出产物

```text
semantic_quality_report.json
semantic_quality_report.md
```

最低 JSON 结构：

```json
{
  "schema_version": "1.0",
  "artifacts_root": "...",
  "project_signature": "... optional",
  "stage_scores": [],
  "blocking_issues": [],
  "warnings": [],
  "summary": {
    "generic_task_ratio": 0.0,
    "placeholder_asset_ratio": 0.0,
    "template_leakage_count": 0
  }
}
```

---

## 验收标准

1. 能检测当前两个测试项目 Step08/09 高相似度。
2. 能检测 `systems` 或 `assets` 关键对象全空。
3. 能检测模板残留文本。
4. 对只读目录运行，不修改任何存档或 stage 产物。
5. 单元测试覆盖空字段、placeholder、模板泄漏、通用任务比例。
