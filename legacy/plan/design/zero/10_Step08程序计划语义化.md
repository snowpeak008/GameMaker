# 10 Step08 程序计划语义化

## 目标

Step08 必须从 `program_capability_contract.json` 和 Project DNA 生成项目专属程序任务，而不是只生成通用 runtime 任务。

## 任务生成规则

1. 保留必要 runtime foundation，但通用任务不得超过 50%。
2. 每个任务必须包含 `project_semantic_refs`。
3. 每个 required capability 必须进入任务或标记 `deferred_with_reason`。
4. 文件名不得使用 `Dev00NFeature.cs`。
5. 任务 title、acceptance、output_files 必须体现项目语义。
6. archetype 额外任务来自数据文件，例如 GridManager、DocumentVerifier。

---

## 门禁

| Code | 中文描述 | 阻断 |
|---|---|---|
| `GENERIC_PLAN_DOMINANCE` | 通用任务占比过高 | 是 |
| `PROGRAM_TASK_WITHOUT_PROJECT_REF` | 程序任务没有项目语义引用 | 是 |
| `CORE_MECHANIC_NOT_PLANNED` | 核心机制没有开发任务 | 是 |
| `LEGACY_DEV_FEATURE_NAME` | 输出文件仍使用 Dev00NFeature 命名 | 是 |

---

## 验收标准

1. 两个不同项目 Step08 任务标题和 output_files 明显不同。
2. Step08 至少 50% 任务为项目专属任务。
3. PvZ 类项目出现格子/阳光/波次/植物放置能力。
4. Papers 类项目出现证件/规则书/批准拒绝/日结能力。
5. `program_semantic_coverage_matrix.json` 覆盖 required Project DNA items。
