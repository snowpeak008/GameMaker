## 报告关系

| 文件 | 职责 |
|---|---|
| `program_ai_review_report.json` | 原程序 AI 评审意见 |
| `program_semantic_review_report.json` | Project DNA 消费、语义覆盖、项目特异性评分 |
| `art_ai_review_report.json` | 原美术 AI 评审意见 |
| `art_semantic_review_report.json` | 资产语义覆盖、placeholder 边界、核心资产缺口 |

任一报告出现 blocking issue，阶段不得静默 success。

---

## 阈值

| 指标 | 阈值 |
|---|---:|
| `required_semantic_coverage` | >= 0.85 |
| `generic_template_ratio` | <= 0.45 |
| `placeholder_ratio` | <= 0.35，音频占位除外 |
| `project_specificity_score` | >= 8.0 |

---

## 验收标准

1. Step05/06 同时输出 AI review 和 semantic review。
2. 可检测通用任务比例过高。
3. 可检测核心资产只有 placeholder 覆盖。
4. 可检测 Project DNA required item 未消费。
5. UI 可读取中文描述和英文 code。
