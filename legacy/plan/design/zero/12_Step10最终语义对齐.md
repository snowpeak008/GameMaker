## 门禁

| Code | 中文描述 | 阻断 |
|---|---|---|
| `SEMANTIC_ALIGNMENT_GAP` | 项目语义未被程序/美术共同覆盖 | 是 |
| `PLACEHOLDER_ONLY_ALIGNMENT` | 只由占位符覆盖核心需求 | 是 |
| `UI_PREFAB_REQUEST_MISSING` | UI 资产没有 prefab 请求 | 是 |
| `PROJECT_SIGNATURE_MISMATCH` | 对齐对象不属于当前项目 | 是 |

---

## 验收标准

1. `gaps=0` 必须代表 required semantic coverage >= 85%。
2. placeholder-only item 不计 fully covered。
3. 缺少核心程序任务或核心资产任务时 blocked。
4. 两个不同项目 semantic alignment matrix 明显不同。
5. Step11-13 可把此报告作为前置依据。
