# 13 UI 阻断返回路径与报告展示

## 目标

让用户在 GUI 中看懂每个 blocked/warning 的中文原因、英文 code、质量分、语义覆盖率和应该返回修复的阶段。

---

## 修改范围

修改：

```text
core/ui/pipeline_panel.py
core/ui/app_window.py
core/ui/main_window.py
core/ui/theme.py
```

按需新增：

```text
core/ui/semantic_quality_panel.py
core/tests/unit/test_ui_semantic_reports.py
```

---

## 显示内容

每步展示：

1. 状态：success / warning / blocked。
2. `project_specificity_score`
3. `required_semantic_coverage`
4. `generic_template_ratio`
5. `placeholder_ratio`
6. 中文问题描述
7. 英文 code
8. 返回修复阶段

---

## 返回路径表

| 阻断代码 | 返回目标 |
|---|---|
| `ARCHETYPE_GENERIC_WITH_STRONG_SIGNALS` | 设计工作台或 Step00 |
| `BLOCKING_OQ_UNRESOLVED` | 设计工作台 OQ 面板 |
| `NULL_CONTRACT_FIELD` | Step02 或 D4 |
| `PROGRAM_CAPABILITY_NOT_BOUND` | Step03 |
| `OBJECTIVE_HAS_NO_COMPLETION_CONDITION` | Step03 或设计工作台目标节点 |
| `CORE_ENTITY_WITHOUT_ASSET_STRATEGY` | Step04 |
| `STYLE_ARCHETYPE_MISMATCH` | Step07 |
| `GENERIC_PLAN_DOMINANCE` | Step08，必要时回 Step02/03 |
| `CORE_ASSET_NOT_PRODUCED` | Step09 或 Step04 |
| `SEMANTIC_ALIGNMENT_GAP` | Step10 根据缺口返回来源阶段 |

---

## 验收标准

1. UI 不裸露英文 code 作为唯一提示。
2. blocked 时用户能看到返回修复阶段。
3. 质量分和覆盖率来自 `customization_score_report.json`。
4. 不影响现有流水线运行按钮和状态刷新。
5. 测试覆盖报告缺失、warning、blocked 三种 UI 状态。
