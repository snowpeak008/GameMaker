# 11 Step09 美术计划语义化

## 目标

Step09 必须从 `art_taxonomy_contract.json` 和 `asset_strategy_matrix.json` 生成项目专属美术任务，避免只生成通用 placeholder。

---

## 修改范围

修改：

```text
pipeline/step_09_art_plan/plugin.py
core/engines/generation.py
knowledge/schemas/ai_design/art_production_task_contract.schema.json
```

新增或扩展：

```text
core/design/art_taxonomy.py
core/tests/unit/test_art_task_semanticization.py
```

---

## 输出产物

```text
stage_09/art_production_task_contract.json
stage_09/art_task_breakdown.json
stage_09/art_semantic_coverage_matrix.json
stage_09/customization_score_report.json
```

---

## 任务生成规则

1. 核心实体、UI 面板、关键反馈至少有资产任务或明确非图片实现策略。
2. `generation_prompt` 必须包含项目语境、资产用途、尺寸、状态、Unity target path、slice/prefab/import 策略。
3. placeholder 只作为 fallback 或音频空文件。
4. placeholder 不计入核心资产 fully covered。
5. 输出路径必须符合现有 art pipeline 的 `Assets/AutoDesign/` 路径策略。

---

## 门禁

| Code | 中文描述 | 阻断 |
|---|---|---|
| `ART_TASK_TOO_GENERIC` | 美术任务过于通用 | 是 |
| `CORE_ASSET_NOT_PRODUCED` | 核心资产没有生产任务 | 是 |
| `PROMPT_MISSING_USAGE_CONTEXT` | 提示词缺少使用场景 | 是 |
| `PLACEHOLDER_ONLY_CORE_ASSET` | 核心资产只有占位符覆盖 | 是 |

---

## 验收标准

1. Step09 核心资产覆盖率 >= 85%。
2. 两个不同项目 art task 差异度 > 80%。
3. PvZ 类项目出现植物/敌人/阳光/HUD/车道相关资产任务。
4. Papers 类项目出现证件/检查台/图章/规则书/UI 相关资产任务。
5. 只有 placeholder 覆盖核心资产时 blocked。
