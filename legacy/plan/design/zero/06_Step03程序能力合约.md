## 门禁

| Code | 中文描述 | 阻断 |
|---|---|---|
| `PROGRAM_CAPABILITY_NOT_BOUND` | 核心语义未绑定程序能力 | 是 |
| `ACTION_HAS_NO_STATE_CHANGE` | 玩家动作没有状态变化 | 是 |
| `RESOURCE_HAS_NO_DATA_MODEL` | 资源没有数据模型 | 是 |
| `OBJECTIVE_HAS_NO_COMPLETION_CONDITION` | 目标没有完成/失败条件 | 是 |

---

## 验收标准

1. 每个 required core entity 至少绑定一个 capability。
2. 每个 player action 有输入、状态变化、反馈或验收。
3. 每个 resource 有数据字段和 UI 展示策略。
4. 每个 objective 有完成/失败条件。
5. Step08 能以 `capabilities[]` 为任务生成主输入。
