# 程序任务语义化优化（Step08）

## 问题描述

当前 Step08 输出的14个任务在两个项目中完全相同，且文件名缺乏游戏语义：

```
DEV-001 → Assets/Scripts/Core/Dev001Feature.cs     ← 无任何游戏语义
DEV-002 → Assets/Scripts/Core/Dev002Feature.cs     ← 同上
```

## 优化方案：任务语义化命名

### 命名规则

输出文件路径从 `Dev{N}Feature.cs` 改为 `{ArchetypeSystem}.cs`：

| 通用任务 ID | 语义描述 | PvZ 输出文件 | Papers 输出文件 |
|-----------|---------|------------|----------------|
| DEV-001 | RuntimeBootstrap | `PvZRuntimeBootstrap.cs` | `PapersRuntimeBootstrap.cs` |
| DEV-002 | GameState | `TowerDefenseGameState.cs` | `DocumentVerifierGameState.cs` |
| DEV-003 | InputRouter | `PlantPlacementInputRouter.cs` | `DocumentInspectorInputRouter.cs` |
| DEV-004 | UIController | `PvZHUDController.cs` | `PapersInspectionUIController.cs` |
| DEV-005 | ObjectiveTracker | `WaveClearObjectiveTracker.cs` | `DayQuotaObjectiveTracker.cs` |
| DEV-006 | SceneBootstrap | `TowerDefenseSceneBootstrap.cs` | `InspectionBureauSceneBootstrap.cs` |
| DEV-007 | CameraRig | `TopDownOrthoCameraRig.cs` | `DeskViewCameraRig.cs` |
| DEV-008 | DataModel | `PlantZombieDataModel.cs` | `DocumentFamilyDataModel.cs` |
| DEV-009 | TestHook | `TowerDefensePlayModeHooks.cs` | `DocumentVerifierPlayModeHooks.cs` |

## Archetype 专属额外任务

除通用 DEV/PLAY 任务外，Archetype 驱动生成额外专属任务：

### tower_defense 额外任务

```
DEV-A01: GridManager — 实现20×5格子地图管理，格子放置/移除/查询
DEV-A02: SunEconomySystem — 阳光生成（自动+植物产出）、消耗、计数
DEV-A03: WaveSpawnManager — 按关卡配置生成僵尸波次，支持延迟和批量生成
DEV-A04: PlantDefenseCalculator — 植物攻击范围、伤害计算、效果应用
```

### narrative_puzzle 额外任务

```
DEV-A01: DocumentVerifier — 证件核验逻辑：对比文件内容与当天规则手册
DEV-A02: RuleBookManager — 规则手册每日更新系统，支持新增/变更规则
DEV-A03: FamilyEconomySystem — 工资计算、家庭支出、危机事件触发
DEV-A04: StoryBranchController — 基于决策的剧情分支记录与跳转
```

## 验收标准

- DEV 任务的 `output_files` 不包含 `Dev00NFeature.cs` 格式
- 两个项目的 Step08 输出文件路径差异度 > 90%
- 每个 Archetype 生成 4+ 个专属额外任务（DEV-A01至DEV-A04）
- 任务 `title` 包含具体字段名和初始值
