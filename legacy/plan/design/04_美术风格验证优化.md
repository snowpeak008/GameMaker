# 美术风格验证优化（Step07）

## 问题描述

植物大战僵尸选择了 `STYLE-04-cinematic_realism`（电影写实风），与其超休闲塔防游戏的卡通彩色风格严重不符。

## 问题根因

Step07 的风格确认是独立的用户确认步骤，没有校验所选风格是否与游戏的：
- Archetype（tower_defense 需要可读性强的卡通风）
- 商业模式（hypercasual 不适合写实风）
- 目标受众（全年龄塔防游戏不适合成人写实风）

## 校验逻辑

在 Step07 `style_confirmation.json` 写入前执行：

```python
def validate_style_compatibility(style_id, archetype, business_model):
    issues = []
    
    # 检查 Archetype 兼容性
    compat = ARCHETYPE_STYLE_COMPATIBILITY[archetype]
    if style_id in compat["incompatible"]:
        issues.append({
            "severity": "ERROR",
            "code": "STYLE_ARCHETYPE_MISMATCH",
            "message": f"{style_id} 与 {archetype} 不兼容",
            "reason": compat["reason"],
            "recommended_alternatives": compat["recommended"]
        })
    
    # 检查商业模式约束
    bm_constraint = BUSINESS_MODEL_CONSTRAINTS.get(business_model, {})
    if style_id in bm_constraint.get("incompatible_styles", []):
        issues.append({
            "severity": "WARNING",
            "code": "STYLE_BUSINESS_MODEL_MISMATCH",
            "message": f"{style_id} 与 {business_model} 商业模式存在风险",
            "reason": bm_constraint["reason"]
        })
    
    return issues
```

## Step07 输出变化

`style_confirmation.json` 中增加：

```json
{
  "status": "approved",
  "selected_style_id": "STYLE-04-cinematic_realism",
  "compatibility_check": {
    "archetype": "tower_defense",
    "result": "INCOMPATIBLE",
    "issues": [
      {
        "severity": "ERROR",
        "code": "STYLE_ARCHETYPE_MISMATCH",
        "message": "cinematic_realism 与 tower_defense 不兼容：写实风格降低单位可辨识度",
        "recommended_alternatives": ["STYLE-02-flat_cartoon", "STYLE-03-vivid_cartoon"]
      }
    ],
    "override_reason": ""
  }
}
```

当 `compatibility_check.result` 为 `INCOMPATIBLE` 且 `override_reason` 为空时，Step07 不能输出 `status: approved`，必须返回 `status: pending_review`。

## 验收标准

- 植物大战僵尸不能以 `cinematic_realism` 通过 Step07（除非用户填写强制覆盖原因）
- 风格推荐列表基于 archetype 自动生成，不硬编码到界面
- 用户可以强制覆盖，但必须填写理由，该理由写入 `override_reason`
